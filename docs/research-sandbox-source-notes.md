# Research Sandbox — Safety and Source Notes

The Research Sandbox is an in-page, local-first planning aid. It does **not** provision virtual phones, virtual computers, remote desktops, anonymous accounts, phone numbers, device identifiers, credentials, network routing, traffic masking, scanning, scraping, or any third-party system access. It is limited to lawful software-testing preparation, evidence-handling reminders, and user-controlled links to official documentation.

| Reference | Appropriate scope in the Hub | Boundary |
|---|---|---|
| [Android Emulator](https://developer.android.com/studio/run/emulator) | Test an application across Android device/API configurations on the researcher’s own computer. | Use for software development and testing only; do not represent simulated devices as real people or accounts. |
| [Apple simulated devices](https://developer.apple.com/documentation/xcode/running-your-app-on-simulated-or-physical-devices) | Build and run an application in a simulated Apple device through Xcode. | Apple notes that simulators do not replicate every physical-device feature; use a physical device for feature verification when authorized. |
| [Windows Sandbox](https://learn.microsoft.com/en-us/windows/security/application-security/application-isolation/windows-sandbox/) | Open an isolated, disposable Windows environment for local application testing. | Networking can be disabled; no external action should be taken without authorization and a lawful purpose. |

The in-app page labels every external destination as opening in a new tab. It does not transmit a user’s plan, evidence, files, personal data, or account details.
